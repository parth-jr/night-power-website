# Night Power — Simple Mobile Site

Files:
- `index.html` — single-page site (Hindi + English)
- `styles.css` — mobile-first styles
- `script.js` — order flow and WhatsApp integration

How to use:
1. Open `index.html` in a mobile browser or desktop.
2. Tap a product and press "Buy Now" or fill the quick order form.
3. Orders open WhatsApp to send a prefilled message to +91 7303040534.

Notes:
- No backend required — uses WhatsApp for checkout and `tel:` links for calling.
- Cash on Delivery supported; add COD confirmation when chatting.
